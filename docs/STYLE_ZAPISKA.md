# Стиль документов для руководства: образец — аналитическая записка v4

Выведено из аналитической записки по риск-аппетиту, версия 4, сентябрь 2026 года.
Это эталонный формат Банка для документов, которые уходят руководству и уполномоченному
органу: записок, отчётов, документов KPI.

**Когда применяется.** Документ читает руководство, согласует уполномоченный орган
или он прикладывается к KPI. Рабочие файлы контуров — `FINDINGS*.md`, `README.md`,
планы и разборы — остаются в стиле репозитория (§5 корневого `CLAUDE.md`). Итоговый
документ из них не копируется, а переписывается по этому руководству.

Исходник записки в репозиторий не кладётся (§2): он промаркирован «ВНУТРЕННЯЯ
ИНФОРМАЦИЯ». Здесь — только выведенные правила.

## 1. Оформление страницы

| Элемент | Значение |
|---|---|
| Формат | A4, книжная |
| Поля | верхнее и нижнее 2,0 см, левое 1,75 см, правое 1,5 см |
| Колонтитул | «ВНУТРЕННЯЯ ИНФОРМАЦИЯ» на каждой странице, включая титульную |
| Шрифт | Times New Roman, 12 пт, во всём документе, включая таблицы |
| Абзац | по ширине, отступ первой строки 1,25 см, интервал после абзаца 8 пт, междустрочный ≈ 1,15 |
| Заголовки | тем же шрифтом и кеглем, что текст, **полужирным**, по левому краю; стили Word «Заголовок» не используются |
| Нумерация заголовков | «1.», «2.»… и «5.1.», «5.2.» — точка после номера; глубже второго уровня не идёт |
| Таблицы | «Сетка таблицы», без заливки; шапка обычным начертанием; текст 10–12 пт; единицы измерения — в шапке |
| Подпись таблицы | **над** таблицей, полужирным: «Таблица 3. Структура портфеля МСБ по группам рейтингов, %» |
| Примечание к таблице | сразу под таблицей, 9–12 пт: «Примечание: …», либо «Примечание:» и маркированный список |
| Формула | отдельной строкой, по центру, полужирным; далее «где:» и маркированный список обозначений |
| Списки | маркер «•» — для перечислений внутри раздела; нумерация «1.» — только в «Выводах» и «Предложениях» |

**Титульный лист** — отдельная страница без номера раздела:

```
                     АНАЛИТИЧЕСКАЯ ЗАПИСКА
      по результатам <чего> — строчными, полужирным, по центру


                           2026 год
```

Никаких дат редакции, номеров версий, имён файлов и ссылок на репозиторий на титуле нет.

## 2. Структура документа

Разделы идут от основания к решению. Каждый следующий отвечает на вопрос, который
возникает после предыдущего. Порядок записки v4 — образец:

| № | Роль раздела | Образец заголовка |
|---|---|---|
| 1 | зачем проводилась работа, на каком основании, что рассмотрено, за какой период | «Цель и основания проведения оценки» |
| 2–4 | факты на отчётную дату и их динамика — без оценок | «Действующие уровни…», «Текущий риск-профиль…», «Динамика структуры…» |
| 5 | где проблема: исключение из общей картины | «Динамика показателя концентрации ТОП-20» |
| 6 | что предлагается сделать с проблемой | «Актуализация уровня показателя ТОП-20» |
| 7–9 | метод и его результат; почему одного инструмента мало | «Оценка запаса…», «Зоны раннего предупреждения», «Почему зоны дополняются триггерами динамики» |
| 10 | перенос на остальные объекты и где метод меняется | «Применение подхода к другим показателям» |
| 11 | проверка на исторических данных | «Результаты исторической проверки предлагаемого подхода» |
| 12–13 | итоговая картина и механизм | «Итоговая оценка…», «Предлагаемый механизм реагирования» |
| 14 | **Выводы** — нумерованный список установленного | «Выводы» |
| 15 | **Предложения** — нумерованный список решений | «Предложения» |
| — | **Приложения** — перечень прилагаемых файлов | «Приложения» |

Заголовок называет **тему**, а не вывод: «Динамика показателя концентрации ТОП-20»,
а не «ТОП-20 растёт». Исключение допустимо, когда раздел отвечает на вопрос «почему»:
«Почему зоны дополняются триггерами динамики».

## 3. Как строится аргумент внутри раздела

Каждый раздел следует одной схеме:

1. **Что сделано.** Первая фраза называет действие безлично: «Для оценки изменения
   риск-профиля проведён анализ структуры кредитного портфеля в разрезе групп
   внутреннего кредитного рейтинга».
2. **Факт с датой.** «По состоянию на 01.07.2026 года…». Число — с датой и единицей.
3. **Таблица**, если чисел больше трёх, — с подписью над ней.
4. **Толкование** — короткими абзацами, по одному утверждению в абзаце.
5. **Итоговая фраза** — «Таким образом, …» или «В целом …». Если это ключевой вывод
   раздела, фраза выделяется полужирным **целиком**.

**Проблема подаётся как исключение из общего правила**, а не как новость: «По большинству
показателей… находятся в пределах… Исключением является показатель… В связи с этим
данный показатель рассмотрен отдельно».

**Выбор обосновывается назначением и фактом**, а не вкусом: «Уровень 90 % выбран исходя
из назначения зон. Зоны являются инструментом раннего предупреждения, а не буфером
поглощения потерь…». Далее идёт второе основание — число: «при 29–35 месячных изменениях
за 90-м процентилем остаётся 3–4 наблюдения».

**Международная практика — одна фраза со ссылкой**, без лекции: «Правило квадратного
корня из времени применяется в международной практике управления финансовыми рисками
для масштабирования риск-метрик на различные временные горизонты (BCBS/BIS)».

**Возражение против собственного вывода** даётся внутри текста, безлично и в сослагательном
наклонении, сразу с ответом. Отдельного раздела «возражения» нет:

> Если бы дата пересчёта выбиралась после того, как известен фактический результат, это было
> бы подгонкой уровня под результат, и служба внутреннего аудита была бы вправе так это
> оценить. Поэтому якорная дата зафиксирована правилом…

> Утверждать, что зоны и триггеры обеспечивают полный контроль показателя, нельзя.

**Проверка ограничивает сама себя:** «Один эпизод R3 не является достаточным статистическим
основанием для подтверждения оптимальности порога эскалации. Историческая проверка
подтверждает работоспособность логики…, однако не доказывает, что…».

## 4. Допущения, ограничения, предварительность

Подаются формулами, а не пометками. Разделение из §5 корневого `CLAUDE.md` — доказано,
взято из документа, гипотеза — сохраняется, но выражается словами документа:

| Что нужно сказать | Как это пишется |
|---|---|
| вывод с оговоркой | «При этом необходимо отметить, что…», «При этом следует учитывать…» |
| цифру нельзя читать напрямую | «…необходимо рассматривать с учётом изменения базы расчёта» |
| результат предварительный | «…носит предварительный характер и подлежит подтверждению после уточнения методологии» |
| решение не наше | «…является предметом отдельного решения уполномоченного органа Банка» |
| источник — документ | «…установлен внутренним документом Банка — Приложением № 3 к Политике»; «Определения приведены дословно по Приложению № 2 к Методике» |
| граница данных | «Анализ исторической динамики проведён за период с августа 2023 года по июль 2026 года» |
| гипотеза | «…вероятной причиной является…; подтверждение требует…». Слово «гипотеза» и номера вида Г-12 в тексте не используются |

## 5. Формулировки

**Залог и лицо.** Безлично-пассивно: «проведена оценка», «рассмотрены», «установлено
следующее», «предлагается». Первое лицо («мы», «я») не используется.

**Связки, которые несут логику:** «В рамках…», «С целью…», «В связи с этим…», «При этом…»,
«Таким образом…», «Иными словами…», «вследствие», «с учётом».

**Термины** вводятся один раз: «АО «Евразийский Банк» (далее – Банк)». Сокращения
раскрываются при первом упоминании. EN-термины — только устоявшиеся: PD, EL, CoR, LGD.

**Числа.**
- Дробная часть — через запятую.
- Проценты — «101,50%», процентные пункты — «п.п.», деньги — «млн ₸».
- Даты — «01.07.2026» или «на 01.07.2026 года».
- Минус — длинным знаком «−».

**Одно утверждение — один абзац.** Абзацы короткие, от одной до трёх фраз.

**Вопрос в тексте** допустим только как формула в кавычках: «зона отвечает на вопрос
«где находится показатель?», а триггер — «с какой скоростью он движется?»».

## 6. «Выводы», «Предложения», «Приложения»

**Выводы** открываются фразой «По результатам проведённой оценки установлено следующее.»
Далее — нумерованный список. Каждый пункт — законченное предложение с числом, повторяющее
вывод раздела, без новых фактов.

**Предложения** открываются фразой «С учётом результатов проведённого анализа предлагается:».
Далее — нумерованный список. Каждый пункт начинается с инфинитива: «Принять…»,
«Рассмотреть вопрос об…», «Сохранить… и дополнить…», «Провести…», «Проводить ежегодно…».
Одно предложение — одно решение.

**Приложения** — перечень прилагаемых файлов: расчётный файл, шаблон и т. п.
Методика и расчёты, не вошедшие в текст, уходят сюда. В тексте на них ссылаются так:
«Детальные результаты проверки приведены в расчётном файле, являющемся приложением
к настоящей записке».

## 7. Что из стиля репозитория в итоговый документ не переносится

| В рабочем файле | В документе для руководства |
|---|---|
| раздел «Сначала возражение», «Чего документ не утверждает» | возражение внутри раздела, безлично, с ответом (§3) |
| «Коротко», «Одной строкой», полужирные подзаголовки внутри абзаца | итоговая фраза «Таким образом, …» |
| пути к файлам, имена скриптов, номера PR, ветки | «расчётный файл, являющийся приложением» |
| внутренние коды (Г-12, Ш-3, Д-7, К-4) без расшифровки | названия по существу; код — только если документ вводит его сам, как R0–R4 |
| блоки кода, схемы из стрелок, эмодзи, легенды ✅ ⛔ | таблица либо нумерованный перечень |
| полужирный на отдельных словах | полужирный только у целой ключевой фразы |
| широкие таблицы со служебными колонками | не больше 5–8 колонок, только то, на что опирается вывод |
