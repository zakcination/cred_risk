# 100 сценариев аналитика для тестирования DWH `Dictionaries.risk_analytics`

Набор реальных запросов, какие приходят в аналитику розничного/корпоративного риска,
разложенный по трём уровням сложности. Назначение — **тестирование DWH**, поэтому у
каждого сценария указано не только «что посчитать», но и **что он проверяет / на какой
ловушке ломается**.

## Как этим пользоваться

Колонка «Что тестирует / ловушка» — главная. Сценарий, который **невозможно** выполнить
корректно из-за известного дефекта, ценнее для теста, чем сценарий, который проходит
гладко: он показывает границу пригодности марта. Ловушки взяты не из головы, а из
`FINDINGS.md` (§1–§9, D4.1/D4.2) и живых прогонов `CASE_RUN_*` этой сессии.

**Критерий прохождения** для каждого сценария — не «запрос вернул строки», а:
1. использован канонический ключ (`*_gid = l_gid AND *_source = l_source`), не имя-похожее поле;
2. NULL отделён от нуля и от «записи нет»;
3. число воспроизводится вторым, независимо написанным запросом;
4. если источники ведут себя по-разному — это видно в разрезе, а не усреднено.

> следом пробы P1–P9. Разбор — `FINDINGS.md` §10–§14. Ловушки со ссылкой `L1/…` или

## Что этот набор НЕ покрывает (честная граница)

- **`collections`, `offbalance`, `credit_lines`** — задействованы только в H21; ни одна
  не имеет собственного дубль-чека и не проверена по покрытию. Отдельная программа
  (см. `DEFECT_REPORT_GUIDE.md`, стратегия 1).
- ~~`interest_rates`~~ — **выведена из этого списка в критический путь.** P7a показал,
  что в `loans` числовой ставки нет вообще, и `interest_rates` оказалась единственным
  источником ставки и ГЭСВ/AIER. Паспорт таблицы строит проба **P8**
  (`sql/DWH_PROBE_P8_INTEREST_RATES.sql`): сетка дат, grain, ключ по покрытию,
  единица измерения.
- **S02 глубоко** — сценарии его затрагивают, но самый рисковый источник (UNION трёх
  карточных таблиц через миграционный обрыв фев-2026) требует собственного набора,
  начиная с шагов 0–4 спирали (`CLAUDE.md` → «Следующий шаг»).
- **Динамика во времени** — H01/H02/H10/H18 сформулированы как аналитик их задаст, но
  на текущем DWH невыполнимы (**T8**). Это результат теста, а не пробел набора.
- **PII-сценарии** (поиск по ИИН/ФИО) сознательно не включены: правило проекта —
  только агрегаты (`CLAUDE.md`).
