## 3. Результаты: карта пригодности

### 3.1 Можно использовать

| Что | Доказательство | Где |
|---|---|---|
| Связь таблиц по `l_gid` | номер договора не глобален (9 659 коллизий между источниками), `l_gid` — ни одной; ставки связываются по `l_gid` на 100 % по всем четырём источникам, график — по трём (S02 в графике нет) | §1, §14, §18.1, §19.2 |

| Валюта, признак POCI, даты выдачи | валюта без пропусков, POCI без противоречий, ни одной выдачи раньше открытия | §10.8 |

### 3.2 Можно, но с оговорками

| Что | Оговорка | Где |
|---|---|---|
| Провизии | расходятся со старой веткой: S03 +30,6 млрд ₸ на совпавших договорах, S17 +29,8 млн ₸. Какая ветка права — без бухгалтерского эталона не решается | §4, §6 |
| Активный портфель | определяется вьюхой `loans_active`, а не статусом: по S17 разница 2 629 договоров | §10.3 |

| График платежей | ведёт договоры вне активного портфеля: у S17 это 63,9 % строк, поэтому соединять только с портфелем | §19.5 |

| Что | Почему | Где |

## 4. Валидация самих тестов

Цикл проверял не только март, но и собственные скрипты. Дефект скрипта, отправленный в БИТ
как дефект марта, стоит времени команды и доверия к следующему письму.

| Где найдено | Дефектов скрипта | Что с ними |
|---|---|---|
| Прогон №1 послойной проверки | 6: не та колонка баланса, сравнение строкой вместо числа, JOIN без приведения типа, вся история против одного среза, ротация вместо целостности ключа, `<=` вместо `<` | исправлены |
| Самопроверка сценариев уровня 3 до запуска | 3 | исправлены |
| Прогон сценариев уровней 2–3 | 4, в том числе вывод ФИО одним сценарием | исправлены; ФИО заменены рангом и хешем |
| Зависание сценария H15 | 1: `CROSS APPLY` до фильтра размножал портфель | исправлено, H15 выполнен отдельно |
| Статическая предпроверка к прогону №2 | 10, из них 3 давали ложно-зелёные вердикты | к исправлению до прогона №2 |

**Отозванные собственные выводы** хранятся в реестре с прежней формулировкой. Главные:
«grain `loans` подтверждён» — отозван 17.07, проверка оказалась тавтологией запроса;
«`l_rate` чинится заменой формата» — опровергнуто пробой: там название программы;
«`loan_account` содержит только S03» — снято: у S03 другая дата среза.

## 5. Взаимодействие

### 5.1 Внутри департамента

- **Две независимые ветки проверки.** Мирас — ключи, grain, периметр; Сайлау — провизии,
  DPD, 90+ и независимый реестр DWH-01…16. Цифры одной ветки не идут в общее письмо,
  пока не перепроверены методом другой (`FINDINGS.md` §9).
- **Адверсариальное ревью.** 12 пунктов по скриптам независимой ветки, затем второй раунд —
  по собственной проверке. Второй раунд отозвал собственный вывод о grain `loans`.
- **Общая карта состояния** — BI-канвас `bi_canvas/dwh_schema_explorer.html`. Методика
  независимой ветки задокументирована (`bi_canvas/SAILAU_METHOD.md`).

### 5.2 С БИТ

**Отправлено — шесть писем по семи дефектам.** К каждому приложен скрипт, который БИТ
может запустить у себя.

| Дефект | Письмо | Дата |

1. Правила загрузки провизий 1428 и 18771 и источник DPD по каждой системе.
