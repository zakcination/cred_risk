**Ловушки сборки Power BI**
- SQL вставляется в окно «Инструкция SQL» при подключении. Вставленный в строку формул
  Power Query, он даёт значок ABC и текст вместо таблицы.
- Время ожидания команды — 30 минут.
- Меры — одной вставкой `PBI_measures.dax` в представление запросов DAX: сначала F5 и сверка
  двух контрольных таблиц, затем «Обновить модель». Ошибка «Не удается определить значение
  для …» означает, что меры нет в модели.
- Динамическая строка формата меры «Значение» включается вручную. Запасной путь —
  «Значение (текст)».

**Ловушки SQL и данных**
- SQL Server пересчитывает CTE при каждом обращении, поэтому факты построены цепочкой, где
  каждое звено читается один раз.
- `OR` в условии `JOIN` мешает hash join — `fact_stage.gk` разнесён на две ветки `UNION ALL`.
- `fact_default` и `fact_vintage` ускорены предфильтром «счета, хоть раз бывшие в 90+».
- История `loan_account` — 21 срез, 01.2025–09.2026, все на 1-е число. В `fact_default` и
  `fact_vintage` нет страховки `DAY(la_reporting_date) = 1`: сегодня это без последствий,
  но срез в середине месяца сломает счёт шести чистых срезов.
- Новые дефолты 01–06.2025 завышены левым цензурированием; надёжный ряд — с 07.2025.
  Знаменатель уровня новых дефолтов за 01.2025 завышен: нет `in_def` за 12.2024.
- S17 связывается со стадией по `la_dog_num`. По базе знаний у S17 одна коллизия номера на
  срез, то есть возможен двойной счёт одного счёта на срез в `fact_stage`. Пренебрежимо, не
  исправлялось.
- Ключ `S17|—|—` оставлен в `dim_product` с пометкой: после обновления витрины 28.09 он пуст.
