# Риск-аппетит: пересмотр уровней по кредитному риску

Рабочее пространство по замечанию СВА **«Не обеспечен ежегодный пересмотр уровней риск-аппетита
по кредитному риску»** (уровень — высокий) и по устно поставленным задачам (предлимиты, меры
реагирования, официальная инструкция расчёта).

БРМ, АО «Евразийский банк». Начато 17.08.2026.

## Контрольные сроки

| Срок | Мероприятие | Артефакт |
|---|---|---|
| до 30.09.2026 | Анализ актуальности действующих уровней РА по кредитному риску с учётом риск-профиля, структуры и качества портфеля и результатов стресс-тестирования | Аналитическая записка |
| до 31.12.2026 | Предложения по сохранению либо актуализации уровней, вынос на УО | Материалы на УО / выписка |
| ежегодно | Статус-отчёт о пересмотре уровней руководству БРМ | Чек-лист / статус-отчёт |

**Срок 31.12.2026 с 01.09.2026 не только наш.** Агентство сократило срок по п. 37 Плана
мероприятий SREP 2023–2024 с 31.12.2027 до 31.12.2026 — предмет тот же документ и тот же
уполномоченный орган, объём шире (добавляется заявление качественного характера).
Срок по п. 38 (два недостающих уровня риск-аппетита) сокращён до 1 квартала 2027.

### Что дал недельный ряд

Собрано **521 наблюдение с 11.05.2016 по 10.08.2026** из оперативных файлов подразделения.

1. **Формула метрики установлена на данных:** доля = (задолженность топ-20 − денежное обеспечение) / СК,

   одномоментное. В момент смены факт был 72–80 %, то есть новый уровень встал примерно на семь σ
   выше максимума — калибровка «от факта плюс запас», не от риск-ёмкости (Г17).
3. **Нарушение мая–августа 2026 — первое за восемь с половиной лет.** Предыдущее закончилось
   06.11.2017. За это время показатель прошёл путь от 276 % до 59 % и держался в 66–84 % (Г18).
4. **74 % скачка сделаны капиталом, а не портфелем.** Точное разложение
   Δ = (N₁ − N₀)/E₀ + N₁·(E₀ − E₁)/(E₀·E₁): Q1 2026 — +14,67 пп, из них портфель −2,99, капитал +17,66

**Сигнальный уровень: факт ≥ 88 % ИЛИ (приращение ≥ 5 пп за отчёт И факт ≥ 85 %).**

### Зоны и меры реагирования (задача 4)

Три правила, каждое выведено из данных, а не из общей практики:

1. **Якорь калибровки — поведение показателя, не лимит.** Отсчёт вниз от лимита («80–90 % лимита»)
   даёт по топ-20 диапазон 76–85,5 %, то есть попадает внутрь обычного операционного коридора
   66–84 % и срабатывает постоянно. Отсчёт вверх от максимума нормального режима такой ошибки
   не допускает. Если доля от лимита попадает внутрь исторического диапазона — подход неприменим
   по этой метрике вовсе.
2. **Зоны лежат строго внутри лимита.** В действующем Приложении № 2 к Методике сделано наоборот:
   по всем восьми метрикам порог красной зоны находится **за** уровнем РА (k1 — 9,0 % против 8,5 %;
   ALRI — 90 % против 85 %). Возникает диапазон, где риск-аппетит соблюдён и одновременно объявлен
   высокий уровень риска (Р1). Повторять нельзя.
3. **Сценарий определяется на каждый период заново.** Разложение Δ на вклад числителя и знаменателя
   механическое и выполняется первым действием. На действующем нарушении сценарий сменился между
   соседними кварталами: Q1 2026 — сжатие знаменателя (C4), Q2 2026 — рост числителя. План
   мероприятий, свёрстанный под один сценарий, второй не закрывает.

Отдельно: контроль по топ-20 должен быть недельным, а не квартальным — ряд ведётся еженедельно.
При квартальном контроле сигнал 02.03.2026 был бы увиден 31.03.2026, и запас сократился бы
с 63 дней до 34.
