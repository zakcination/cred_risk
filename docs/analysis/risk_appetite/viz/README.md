## Схема цепочки

```
python3 chain_svg.py          # -> chain.svg
python3 chain_svg.py --png    # + chain.png для вставки в .docx (нужен playwright)
```

| Файл | Что показывает |
|---|---|
| `chain.svg` | Шесть звеньев каскада «риск-ёмкость → риск-аппетит → лимит → допустимый уровень → мера реагирования → контроль», состояние каждого и разрывы между ними, с ссылками на пункты и на находки реестра |

Источник истины — `chain_svg.py`. Правится он, а не `.svg` и тем более не `.png`: PNG нужен
только потому, что docx-js не принимает SVG, и всегда пересобирается из источника.

Схема утверждает три вещи, и все три проверяемы по реестру: целиком есть **одно звено из шести**
(лимит), отсутствуют звенья **1, 4 и 5**, и происхождение уровня восстановлено ровно для **одного
лимита из 25**.

## Два сгенерированных кадра

`info_chain.png` и `info_wall.png` — не экспонаты, а разделители глав. Они **не несут аргумента
и не содержат ни одной цифры**: генеративная модель не рисует точных подписей, и попытка вложить
в неё аналитику даёт красивую неправду.

| Файл | Что изображено | Какую главу открывает |
|---|---|---|
| `info_chain.png` | Цепь из шести звеньев: два целых, третье с трещиной, четвёртое и пятое — только проволочные контуры, шестого нет | Цепочка «риск-ёмкость → риск-аппетит → лимит → допустимый уровень → мера → контроль» и её фактические разрывы |
| `info_wall.png` | Стеклянная преграда, годами нетронутая, и обрушившийся под ней грунт | Уровень не был перейдён — упал знаменатель |

В промпты не передавались ни данные Банка, ни названия, ни цифры — только абстрактная геометрия.
Точные схемы с подписями собираются как SVG, а не генерируются, — см. `chain.svg` выше.

## Правила оформления

Палитра и типографика — из методики визуализации, светлый режим: поверхность `#fcfcfb`,
основной текст `#0b0b0b`, категориальные слоты `#2a78d6` / `#eb6834` / `#1baf7a`,
статусные цвета `#d03b3b` / `#fab219` / `#0ca30c` зарезервированы за состоянием и никогда
не используются как «ещё один ряд».

Три правила, которые нарушать нельзя:

1. **Одна ось.** Ни одного графика с двумя шкалами Y. Две величины разного масштаба —
   это два графика, а не один с двумя осями.
2. **Цвет закреплён за сущностью, а не за рангом.** Синий — портфель, оранжевый — капитал,
   на всех экспонатах одинаково.
3. **Подписи — выборочные.** Число ставится там, где оно несёт аргумент, а не над каждой точкой.

Каждый экспонат несёт подпись источника внизу. Если число в графике расходится с числом
в записке — правится CSV, а не график.
