## Правила оформления

Палитра и типографика — из методики визуализации, светлый режим: поверхность `#fcfcfb`,
основной текст `#0b0b0b`, категориальные слоты `#2a78d6` / `#eb6834` / `#1baf7a`,
статусные цвета `#d03b3b` / `#fab219` / `#0ca30c` зарезервированы за состоянием и никогда
не используются как «ещё один ряд».

Три правила, которые нарушать нельзя:

1. **Одна ось.** Ни одного графика с двумя шкалами Y. Две величины разного масштаба —
   это два графика, а не один с двумя осями.
2. **Цвет закреплён за сущностью, а не за рангом.** Синий — портфель, оранжевый — капитал,
   на всех экспонатах одинаково.
3. **Подписи — выборочные.** Число ставится там, где оно несёт аргумент, а не над каждой точкой.

Каждый экспонат несёт подпись источника внизу. Если число в графике расходится с числом
в записке — правится CSV, а не график.

Экспонат 1 показывает режимы уровня и эпизоды превышения, но **не** линию самого показателя:

не выкладывается. Рисовать линию по агрегатам значило бы её выдумать.
