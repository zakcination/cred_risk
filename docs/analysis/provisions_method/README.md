## 2. Коллективная основа — Приложение 4. Полная цепочка

### 2.1 Вход: поколения и корзины

Единица наблюдения — заём, сгруппированный в **поколение выдачи** `i = ГГГГММ`
(4.3, лист `base`: `=TEXT(due_date;"ГГГГММ")`). Возраст — месяцы с даты выдачи. Месяц
дефолта считается с оговоркой, видной только в формуле: **если дефолт наступил в первые
три месяца, он относится к третьему** (`IF(months<=3;3;months)`). То же для месяца
закрытия. История выдач — с 2012 года (Приложение 4, Раздел 1).

Группы ПОЗ (Приложение 4.1): беззалоговые внешних клиентов (портфели 2, 8, 9.2–9.4);
беззалоговые зарплатных проектов (4, 9.1); кредитные карты (11); авто (3, 10); ипотека
и обеспеченные недвижимостью (1); карты в рассрочку (12); МСБ, кроме существенных (6, 7).

### 2.2 Этап 1 — PD

**Уровень дефолта по поколению и возрасту** (4.3, лист `Result`):

    DR(i, j) = D(i, j) / N(i, j)

где `D(i, j)` — прирост дефолтов поколения `i` в месяце `j` (лист `Default increment`),
`N(i, j)` — недефолтные на начало месяца `j` (лист `Non default`). Для первого месяца
с дефолтами `N` равно числу выдач поколения (текст, пп. 2).

**Усреднение по поколениям, достигшим возраста `j`:**

    PD(j) = mean_i DR(i, j)                              — строка 78: =AVERAGE(столбец)

**Выживаемость и аннуализация** (строки 79–91 листа `Result`, формулы дословно):

    S_obs   = Π_j (1 − PD(j))                            — 1 − PD за период наблюдения
    p_m     = 1 − S_obs ^ (1 / n)                        — месячный PD, n = max наблюдаемый возраст
    PD_12   = 1 − (1 − p_m) ^ 12                         — аннуализированный, наблюдаемый
    PD_LT   = 1 − (1 − p_m) ^ k                          — на весь срок, k = Max Age продукта

**Если история короче срока продукта** (`n < k`) — экстраполяция, которой в тексте
нет, а в таблице есть:

    g       = GEOMEAN( 1 − PD(j) для последних 6 месяцев наблюдения )   — строка 87
    S_k     = S_obs × g ^ (k − n)                                        — строка 88
    p_m'    = 1 − S_k ^ (1 / k)                                          — строка 89
    PD_12'  = 1 − (1 − p_m') ^ 12                                        — «скорректированный»
    PD_LT'  = 1 − (1 − p_m') ^ k

В образце приложения `k = 180` месяцев, `n = 71`: `PD_12' = 3,07 %`, `PD_LT' = 37,35 %`.
Показатель `k` берётся из описаний продуктов в ВНД, а не из данных (текст, п. 7 б).

**Оговорки текста, которые меняют базу (п. 7):** при полном цикле жизни поколений
`k = n`; **оздоровленные займы исключаются из дефолтов на дату расчёта, а повторный
дефолт после оздоровления получает новую дату дефолта** (п. 7 г); по продукту CAR CL
PD считается как при завершённом цикле, хотя цикл не завершён (п. 7 д).

**PIT-калибровка** (Приложение 4.8, формулы дословно):

    PIT = DR_expected / mean(DR_2012..2017)
    DR_expected = b0 + b1·ИПЦ + b2·темп промпроизводства + b3·индекс физобъёма + b4·CDS
    PD_PIT = PD × clamp(PIT; 0,95; 1,15); при 0,99 < PIT < 1,01 калибровка не применяется

Регрессия оценена на **шести годовых точках 2012–2017 при четырёх регрессорах
и свободном члене** — пять параметров на шесть наблюдений. Пересчёт — раз в год, через
два месяца после конца третьего квартала (п. 6).

### 2.3 Этап 2 — EAD, RR, TV, LGD

**EAD** поколения дефолта `i` — сумма задолженности займов, вышедших в дефолт в месяце `i`.

**Уровень возврата** (4.5, лист `result`, формула F6 дословно):

    RR(i, j) = min( R_disc(i, j) / (EAD_i + C_i) ; 1 )

где `R_disc` — платёж месяца `j` после дефолта, дисконтированный по эффективной ставке
договора к дате дефолта; по валютным займам — с поправкой на курс `V0 / V` (текст).
Оговорки текста: платежи коллекторской компании учитываются, оздоровленные исключаются,
**потоки от реализации залога исключаются** — они идут через TV. Ставки из RS-Bank
ниже 8 % и выше 150 % считаются некорректной выгрузкой и заменяются (текст).

**Столбец `C_i` в знаменателе не подписан** ни в `Basic Data`, ни в `result` и в образце
пуст. Это находка П-1 (§ 5).

    AvgRR(j)    = mean_i RR(i, j)                        — строка 82
    CumRR(j)    = Σ_{t ≤ j} AvgRR(t)                     — строка 83
    LGD_noTV    = max( 0 ; 1 − CumRR(n_max) )            — строка 85
    LGD         = LGD_noTV − mean_i ( TV_disc_i / EAD_i ) — строка 86

**Ликвидационная стоимость TV** (текст, п. 4 этапа 2; коэффициенты — 4.4 и 4.4 а):

    TV_disc_p = ( Collateral_p × k_liq × k_price ) / (1 + r) ^ t + Pledge_money_p
    TV_p      = min( TV_disc_p ; задолженность_p )
    TV_i      = Σ_p TV_p по займам поколения i

`k_liq` — коэффициент ликвидности по виду обеспечения (недвижимость всех типов — 0,7);
`k_price` — коэффициент изменения стоимости залога по региону, типу и месяцу выдачи
(Алматы, квартиры: от 0,91 в январе 2005 до 0,32 к концу 2005 года; авто — отрицательные
значения, то есть обесценение); `t` — срок взыскания в годах, **от 6 месяцев**; по
реализованному залогу берётся цена реализации.

### 2.4 Этап 3 — ожидаемый возврат ER

    ER(m) = min( Bal_current ; TV_m + Σ_{j ≥ m} AvgRR(j) × EAD_m )

`m` — число месяцев с момента дефолта данной генерации. То есть от генерации возраста `m`
ожидается **остаток кривой возврата**, начиная с её собственного возраста, плюс залог.

### 2.5 Этап 4 — провизии (4.2, лист `Product`, формулы дословно)

| Корзина | Провизия | Формула в таблице |
|---|---|---|
| 1 (0–29), IBNR | `V × PD_12 × LGD` | `=D17*C10*C12` |
| 2 (30–90), IBNR | `V × PD_LT × LGD` | `=D18*C11*C12` |
| 3, генерация `m` | `max( V(m) − ER(m) ; 0 )` | `=MAX(D19-E19,0)` |
| % по генерации | `Prov(m) / V(m)`; при `V(m) = 0` — среднее соседних генераций | `=IF(D<>0;F/D;AVERAGE(G_prev;G_next))` |

    Provisions_total = Σ_m Prov(m) + Prov_IBNR_0-29 + Prov_IBNR_30-90
    Provisions %     = Provisions_total / GBV_portfolio

База IBNR — займы, **никогда не бывшие в 90+ либо погасившие эту просрочку** и имеющие
на дату расчёта просрочку до 30 дней (корзина 1) или 30–90 (корзина 2). Оздоровленный
заём возвращается в базу IBNR.

**Посадка в АБС** (текст, п. 6): проценты считаются по корзинам «**когда-либо**» —
первого выхода в дефолт — и переносятся на текущие корзины фактической просрочки:
`Prov'(m) = Prov%(m) × V(m)` с округлением до 2 знаков по займу, затем
`Prov%(h) = ROUND( Prov'(h) / V(h) ; 4 )` по фактической корзине `h`. Дата «когда-либо»
фиксируется как дата первого события из п. 5 и **сбрасывается оздоровлением** (п. 7 г).

### 2.6 Признаки обесценения и оздоровление (п. 5, пп. 12–13)

Обесцененным на коллективной основе считается заём при одном из пяти событий:
просрочка более 90 дней; реструктуризация из-за ухудшения финансового состояния, в том
числе при просрочке 30 дней и более; смерть; лишение свободы; банкротство в любой из
четырёх форм. Оздоровление — **два этапа**: из корзины 3 в корзину 2 при погашении,
снижающем ВБС; из корзины 2 в корзину 1 при отсутствии SICR на дату формирования.
Разбор этапов и их сроков — контур `dpd15_cure`, здесь не повторяется.

## 3. Индивидуальная основа — Приложение 2. Три формулы EL

| Состояние актива | Формула | Где считается |
|---|---|---|
| Корзины 1–2 | `EL = Σ_{t=1..T} PD_t × LGD_t × EAD_t × D_t` | КХД, модель 2.6 |
| Корзина 3, ВБС ≤ 0,2 % СК (и ≤ 180 млн ₸ — п. 14 методики) | `EL = GBV × LGD`, где `LGD_1-2b = 1 − (AvgRR + PV2 / GBV)` | КХД |
| Корзина 3, ВБС > 0,2 % СК | `EL = GBV − (PV1 + PV2)`; при этом `LGD_3b = EL` в абсолютном выражении | Oracle BPM |

**Горизонт `T`** — 12 месяцев для корзины 1, весь срок для корзины 2. **`D_t`** — дисконт
по первоначальной эффективной ставке; при плавающей ставке — текущая (п. 7 методики).

**PD для не-розницы** — от рейтинга (Приложения 5–10) через исторические миграции:
LTPD получается **матричным произведением** матриц миграций (Глава 2 Приложения 2);
далее

    Marginal_PD(y)  = 1 − (1 − LTPD(y)) / (1 − LTPD(y−1))
    Marginal_PD_Int = 1 − (1 − Marginal_PD(y)) ^ (n / 12)      — линейная интерполяция внутри года

**SICR** (Раздел 2 Приложения 2): превышение LTPD PIT на отчётную дату над LTPD PIT
на дату признания; заёмщики с рейтингом не ниже BBB− по S&P или эквивалентом — вне
критерия.

**EAD корзин 1–2** (Раздел 5): по действующим графикам с начисленным вознаграждением
по прогнозируемым остаткам; допускается понижающий коэффициент досрочных погашений
при наличии статистики; без графика — погашение в конце срока, при разнице дат менее
30 дней — через 30 дней после окончания.

**PV1** — потоки от деятельности заёмщика, `Σ CF_t / (1 + r)^t`; **не учитываются**,
если операционная деятельность не подтверждена, **последний мониторинг старше четырёх
кварталов**, связи с заёмщиком нет либо прогноз может быть существенно искажён.
**PV2** — потоки от реализации обеспечения, по каждому виду отдельно, той же формулой.
Пересмотр ставки резерва: ежемесячно при долге ≥ 2 млрд ₸, ежеквартально при меньшем.

**Условные обязательства** (Раздел 6):

    ГР_уо      = P' × ГР_з
    P'         = Σ_i P_i(ann) × D_i / 4 × Q
    P_i(ann)   = P_i / M_i × 12

`P_i` — доля раскрывшихся условных обязательств поколения выдач `i`, `M_i` — его возраст
в месяцах, `D_i` — вес поколения, `Q` — доля нарушивших условия обслуживания среди
раскрывшихся, `ГР_з` — средневзвешенный процент резервирования по займам корзин 1–2.
Шаблон — Приложение 2.4.

## 3а. Межбанк — Приложение 3. Третья ветвь расчёта

Периметр: межбанковские вклады, межбанковские займы и деньги на корреспондентских счетах.
Формулы EL те же, что в Приложении 2, но три входа устроены иначе.

**SICR задан формулой, а не текстом** (3.2, ячейка стадии):

    стадия = 2, если (LTPD_отч − LTPD_призн) / LTPD_призн > 0,80
             либо максимальная просрочка > 30 дней
             либо флаг прочих факторов = 1
             иначе 1

Порог **80 % относительного прироста LTPD** совпадает с текстом. Контрагенты с рейтингом
не ниже BBB− по S&P или эквивалентом выведены из-под критерия. По требованиям к НБ РК
и Казахстанской фондовой бирже **LGD = 0 %**.

**PD берётся не из данных Банка, а из таблицы S&P** — Приложение 3.6, кумулятивные
частоты дефолта по рейтингам от AAA до CCC/C на горизонте 1–10 лет. Marginal PD
считается тем же преобразованием, что для не-розницы. Подпись под таблицей —
**«2016 Annual Global Corporate Default Study»** (находка П-13).

**LGD не эмпирический, а подогнанный** (3.5). Таблицы 1–2 содержат данные Moody's
о возвратах по рейтинговым группам, но в расчёт идёт Таблица 3, где

    LGD(n) = 0,41455 × 1,02798 ^ n,   n — номер рейтинговой ступени 1…17,
    затем ROUND(·; 2)

Кривая даёт 0,43 для AAA и 0,55 для BBB−. Эмпирические значения из тех же таблиц
существенно иные: Aaa — 0,313, Aa — 0,599, A — 0,587, Baa — 0,570 (находка П-12).

## 3б. Рейтинговые модели — Приложения 5–10. Откуда берётся ВКР

PD не-розницы и межбанка входит через внутренний кредитный рейтинг, а он считается
балльно: сумма произведений «фактический балл × весовой коэффициент» по группам
показателей, затем диапазон итогового балла отображается в рейтинговую группу.

| Приложение | Периметр | Группы показателей |
|---|---|---|
| **5** | корпоративный бизнес | четыре: документально подтверждённые качественные, финансовые, отраслевые, прочие качественные. Отдельно считается рейтинг сделки и инвестиционный рейтинг |
| **6** | МСБ medium | четыре, те же группы |
| **7** | МСБ small | балльная, без отраслевого блока |
| **8** | МСБ micro (физлица-предприниматели) | балльная |

## 4. Пруденциальная методика — как она связана с МСФО

| Пункт | Правило |
|---|---|
| **п. 6** | Пруденциальные провизии = задолженность − дисконтированные будущие потоки. **Если провизии по МСФО больше — признаются они.** Периодичность расчёта — **не реже раза в 6 месяцев** |
| п. 7 | Отдельно по обесцененным индивидуальным; коллективно — по необесцененным индивидуальным и по однородным |
| п. 11 | Заём оценивается коллективно, если не индивидуальный, либо признаков нет, либо признаки есть, но приведённая стоимость потоков выше задолженности |
| п. 12 | По требованиям к Правительству, НБ РК, национальным холдингам и под их гарантии — не рассчитываются; признаётся не меньше МСФО |
| п. 15 | Коллективная основа — по внутренней методике Банка по каждому портфелю; при появлении признака обесценения индивидуальный заём выводится из портфеля в Приложение 2 |
| п. 26 | **Положительная разница** (превышение пруденциальных над МСФО) ежемесячно уменьшается на провизии по полностью погашенным и списанным займам |

То есть у Банка **две величины провизий на один актив**, и в учёт идёт большая. Разница
между ними — регуляторная надбавка, которая живёт своей жизнью с полугодовым шагом.

## 5. Находки — только то, что видно из документов и формул

| Код | Находка | Основание | Статус |
|---|---|---|---|
| **П-1** | В знаменателе уровня возврата стоит **неподписанный столбец** `C`: `RR = R / (EAD + C)`. В образце он пуст, в описании переменных не назван. Если это, например, начисленное после дефолта вознаграждение — RR занижается, LGD завышается; если списание — наоборот | 4.5, `result!F6`; `Basic Data` строка 3 | вопрос владельцу |
| **П-2** | **Все формулы текстовых приложений — OLE-объекты Equation 3.0.** В извлечённом тексте они отсутствуют; в современных редакторах без Equation Editor не открываются. Методика в распространяемом виде **не читается полностью** без устаревшего ПО | Приложение 4: 69 объектов; Приложение 2: 9 | документально |

Уточнено находкой П-11 | 4.8, строки 7–17 | документально; связь с Г21 — гипотеза |

При **1 < x ≤ 1,15** она возвращает **ЛОЖЬ**, а ЛОЖЬ в умножении даёт **ноль**: `PD × ЛОЖЬ = 0`. Диапазон 1…1,15 — это ровно тот случай, когда макросреда ухудшилась и PD должен быть **повышен** до 15 %; вместо повышения провизии по этой ветви обнуляются. Сегодня дефект латентен: коэффициенты равны 0,777 (ИА) и 0,907 (ОА), оба зажимаются в 0,95. Отдельно: **нейтральная полоса 0,99–1,01, требуемая текстом, в формуле отсутствует вовсе** | 2.7 `I10`; 4.8 `I9` — формулы совпадают посимвольно | **доказано разбором формулы**; проверено на сетке значений |
