# Сегментация НСТ: тринадцать портфелей и наши коды

Сегментация для НСТ «согласована со структурой активов, используемой для проведения
AQR» (Методруководство, п. 28); первичная сегментация выполняется в рамках AQR
и «может отклоняться от приведённых критериев» (п. 29). Обновлено 20.08.2026.

## 1. Портфели НСТ, коды сегментов и охват анализом

Таблица 3 Методруководства задаёт, какие портфели анализируются в кредитном риске,
а какие — только в чистом процентном доходе.

| Портфель НСТ (Таблица 3) | Код в нашем SQL | Кредитный риск | ЧПД |
|---|---|---|---|
| Займы финансовым институтам | — | не анализируется | анализируется |
| Займы государственным структурам | — | не анализируется | анализируется |

| Инвестиционные займы | `CORINV` | анализируется | анализируется |
| Займы на приобретение, строительство недвижимости | `COREST` | анализируется | анализируется |
| Займы государственным корпорациям | `CORGOV` (в скрипте закомментирован) | анализируется | анализируется |

| Потребительские кредиты, кредитные карты и прочие займы ФЛ | `RETCON` | анализируется | анализируется |
| Займы ЛСБОО | `RELATE` | анализируется | анализируется |
| **Индивидуальные займы** | `Individual loans` | **распределены по другим портфелям** | анализируются |
| **Займы, переданные в ОУСА** | `DISASS` | **распределены по другим портфелям** | не анализируются |

> **Находка 1.** «Индивидуальные займы» и «Займы, переданные в ОУСА» в AQR — отдельные
> портфели (и в результатах AQR-2025 идут отдельными строками: 501,3 млрд ₸ и 9,1 млрд ₸),
> но **для кредитного риска НСТ они распределяются по другим портфелям**. Наш скрипт
> выделяет их как самостоятельные значения `segment_afr`, и правило перераспределения
> нигде не реализовано. Требуется отдельный шаг: разложить эти два сегмента по
> продуктовым портфелям — по исходным признакам заёмщика и займа, а не по факту
> попадания в список B2A или в ОУСА.

## 2. Критерии отнесения в действующем скрипте

Порядок ветвления `CASE` (первое совпадение выигрывает):

1. `ENTITY = 'EUB1'` → `DISASS` — передано в ОУСА;
2. `LSBOO = 1` → `RELATE` — лицо, связанное с банком особыми отношениями;
3. `F_INV = 1` → `CORINV` — инвестиционный заём;
4. заёмщик найден в списке B2A → `Individual loans`;
5. сумма задолженности по заёмщику (окно по `IIN_BIN`) ≥ 0,2 % капитала → `Individual loans`;
6. `(DEBTOR_TYPE = 1 или DEBTOR_TYPE = 0 и DEBTOR_SE = 1)` и `ENT_TYPE in (1,2,3)`
   и `LOAN_OBJ in (1,2,3)` и `LOAN_PURP in (1,2,3,4,5,8)` → `COREST`;
7. `ENT_TYPE = 1` → `CORLAR`; `= 2` → `CORMED`; `= 3` → `RETSML`;
8. ФЛ, EAD ≤ 200 млн, не ИП, `portfolio = 'Mortgage'` → `RETEST`;
9. ФЛ, EAD ≤ 200 млн, не ИП, `collateral = 1` → `RETCAR`;
10. ФЛ, EAD ≤ 200 млн, не ИП, `collateral = 0` → `RETCON`;
11. иначе → `X`.

Критерий индивидуально значимого займа (шаг 5) — порог 0,2 % от собственного капитала;
в скрипте капитал зашит числом на 01.01.2025.

## 3. Фактическое распределение (файл сегментов, 729 787 договоров)

| Сегмент | Договоров | Доля |
|---|---|---|
| `RETCON` | 621 462 | 85,16 % |
| `RETCAR` | 103 401 | 14,17 % |
| `RETSML` | 2 227 | 0,31 % |
| `CORMED` | 1 249 | 0,17 % |
| `RETEST` | 794 | 0,11 % |
| `CORLAR` | 605 | 0,08 % |
| `COREST` | 49 | 0,01 % |

> **Находка 2.** В выгрузке присутствуют только семь кодов. Отсутствуют
> `Individual loans`, `RELATE`, `DISASS`, `CORINV`, `CORGOV` и `X`. При этом
> в результатах AQR-2025 «Индивидуальные займы» — крупнейший портфель по объёму
> (501,3 млрд ₸), а «Займы ЛСБОО» и «ОУСА» присутствуют. Возможные объяснения:
> файл содержит только часть периметра, либо сегментация выполнена другой версией
> скрипта. **До начала расчёта установить, какой это срез** — иначе метрики будут
> считаться не по тому периметру.

> **Находка 3.** Ни одного `X` — либо все займы классифицированы, либо строки с `X`
> отфильтрованы при выгрузке. Требуется контроль: доля `X` и доля `segment_afr IS NULL`
> должны считаться и предъявляться явно, а не молча исчезать.
