# Порядок работ по НСТ (кредитный риск)

Шаги идут в том порядке, в котором договорились: сначала общий язык, потом данные,
потом модель. Обновлено 20.08.2026.

## Шаг 1. Синхронизация определений — сделано частично

Готово: словарь метрик с дословными формулировками регулятора (`GLOSSARY.md`),
карта сегментов (`SEGMENTS.md`), разделение допущений на три группы (`ASSUMPTIONS.md`).

Осталось: пройти пять открытых вопросов `GLOSSARY.md` с методологами провизий
и с автором расчёта AQR. Главный — соотношение годовой PD и квартальных TR.

## Шаг 2. Синхронизация понимания

Проверяется не словами, а числом: берём один портфель (предлагается `RETCON` —
85 % договоров) и независимо считаем по нему TR¹⁻², TR¹⁻³, LGD и покрытие
провизиями двумя руками. Совпали до второго знака — понимаем одинаково.
Не совпали — разбираем, на каком шаге разошлись.

## Шаг 3. Подготовка данных

1. Контрольные запросы из `SQL_REVIEW.md` (замечания 3, 4, 10): доля `NULL`, `X`,
   заглушек, распределение `stage_b`.
2. Установить периметр файла сегментации (`SEGMENTS.md`, находка 2).
3. Собрать ряды переходов по кварталам: для TR нужны **пары срезов** (начало и конец
   квартала) на уровне договора, а не только остатки на дату.
4. Восстановить историю: два года AQR-циклов дают ограниченное число точек — оценить,
   хватает ли наблюдений для модели по каждому сегменту или потребуется объединение
   портфелей (как это уже сделано в AQR-2025 для пяти корпоративных, `ASSUMPTIONS.md`, Б7).

## Шаг 4. Ограничения и допущения

Заполнить `ASSUMPTIONS.md` разделом «требует решения» — семь открытых позиций,
по каждой нужен владелец и срок.

## Шаг 5. Модель TR и LR

Регулятор не предписывает класс модели (`GLOSSARY.md`, раздел 5) — требование одно:
метрики point-in-time, чувствительные к макропараметрам сценария. Если выбираем
регрессию на макрофакторах:

- ряды привести к стационарности (иначе связь ложная) — приросты, логарифмы,
  проверка единичного корня;
- TR ограничены отрезком [0, 1] — линейная регрессия на уровнях неуместна,
  нужна логит- или пробит-трансформация;
- число наблюдений мало (кварталы за два-три года), поэтому число регрессоров
  должно быть минимальным: один-два макрофактора на уравнение;
- знак коэффициента должен быть экономически объясним (рост безработицы повышает
  TR¹⁻³, рост ВВП понижает) — иначе модель не примут, даже если она статистически
  хороша;
- проверка на устойчивость: вне выборки и на стрессовом сценарии значения не должны
  выходить за разумные границы.

## Шаг 6. Сверка с шаблоном

Инструкция к шаблону НСТ (65 стр.) задаёт состав листов и контроли. Пройти
по листам и отметить, какие поля закрываются нашим расчётом, а какие требуют
данных от смежных подразделений.

## Шаг 7. Пояснительная записка

Обязательна по п. 78: описание методологии определения параметров на отчётную дату
по каждому портфелю. Черновик собирается из `GLOSSARY.md` и `ASSUMPTIONS.md`.
