# Cure_of_dpd_15: оздоровление розничных займов при пороге DPD 15 дней

Контур создан 24.08.2026. Проверяемый вопрос: **нарушается ли нормативный пункт, если порогом
DPD для оздоровления займов физических лиц взять 15 дней.**

## Проверяемая конструкция

| Параметр | Значение |
|---|---|
| Периметр | розница, физические лица, активы в дефолте |
| Портфель | на 01.08.2026, ретроспектива 6 месяцев |
| Наблюдения | отчёты только на 1-е число: 01.02 — 01.08.2026, **7 срезов** |
| Критерий по просрочке | DPD **≤ 15** дней, проверяется **только на отчётную дату** |
| Критерий по платежам | 6 платежей подряд |
| Ограничение | отсутствие действующей отсрочки |
| Критерий по сумме | снижение основного долга |

## Ответ

**Нормативного пункта, который нарушал бы порог 15 дней, нет.** Все пороги дней в проверенных
документах — пороги ухудшения, и каждый выше 15. Развёрнуто — в `FINDINGS_DPD15.md`, раздел
«Прямой ответ» и «РЕШЕНИЕ».

Риск находится в другом: в шестимесячном периоде (Н1), в отсутствии критериев в Методике (Н4),
в согласованности определения дефолта между учётом и моделью (Н5, Н8) и в разрешающей способности
месячной сетки (Н9).

**Но «не нарушает» ещё не значит «безопасно».** Вопрос, решающий дело, — возвращаются ли
оздоровлённые по мягкому правилу в дефолт чаще, чем оздоровлённые по строгому. Конструкция
проверки — в `GO_NOGO.md`, результат — в `RESULTS_D15N.md` и `RESULTS_D15O.md`.

**Измеренный ответ (01.09.2026):** цена порога мала и знак её зависит от срока выхода
(±4 п.п.), тогда как срок выхода сам по себе даёт разрыв в 33 п.п.: оздоровлённые
на первой достижимой контрольной точке срываются в 47,4 % против 14,2 % у остальных.
Разрыв не объясняется ни винтажом, ни продуктом, ни форой снимка. Почти половина ранних
оздоровлений просрочена уже через месяц после «оздоровления».
**Решающее — длина подтверждения, а не высота порога.**

## Проверенные источники

Прочитаны в оригинале и цитируются по номерам пунктов:

- **Правила № 61** от 29.09.2025 — создание провизий по МСФО (Минюст № 36994). Ключевые: п. 15
  (переход между стадиями), п. 16 (объективные подтверждения обесценения), п. 25 (содержание
  Методики), определения 4) и 5)
- **Нормативы № 85** от 28.04.2026 — определение неработающих займов, лимиты главы 11
- **Правила № 86** от 28.04.2026 — требования к методологии моделей оценки вероятности дефолта
- **МСФО (IFRS) 9** — п. 5.4.2, 5.5.7, 5.5.11, B5.5.19, B5.5.20, B5.5.37

Тексты нормативных актов в репозиторий не выкладываются: здесь только результаты анализа со
ссылками на пункты.

## Связь с другими контурами

Неработающие займы по Нормативам № 85 определены через признаки обесценения по Правилам № 61,
то есть **НЗ = Stage 3**. Изменение критерия оздоровления напрямую двигает лимит главы 11,
который в контуре `npl_limits` уже сработал. Это не нарушение, но требует раскрытия отдельной
строкой при вынесении.
