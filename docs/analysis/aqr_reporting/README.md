Оптимизация процесса подготовки отчётности AQR. Заведён 14.09.2026 по требованию
**KPI II квартала 2026 «Анализ и оптимизация процесса AQR»**.

**Обновлено 14.09.2026:** контур заведён. До этого работа существовала вне репозитория:
аналитическая записка с восемью приложениями финализирована 10.08.2026 и передана
заместителю руководителя, но следа в `main` не оставила. Прогон сборщика, на котором
она построена, датирован **09.08.2026** — днём первого коммита репозитория.

## Ground truth

Все величины контура получены **прогоном сборщика журналов от 09.08.2026** и
пересчитываются из выгрузок каталога `_MASTER_OUTPUT`. Корпус — 8 291 920 строк
журналов ошибок за два цикла после снятия дубликатов; контрольная величина
воспроизведена тремя прогонами и совпала до строки.

Опорные числа, на которые ссылаются оба документа:

| Величина | Значение |
|---|---|
| Строк журналов, два цикла | 8 291 920 |
| в том числе цикл 2026 | 2 908 225 |
| Итераций журнала: 2025 → 2026 | 7 → 6 |
| П-1, расхождения классификаторов: 2025 → 2026 | 4 207 116 → 4 191 |
| Расхождение кредитных линий B1A/B1B: 2025 → 2026 | 8 117 → **1 211 730** |
| Формальные ответы «прошлая ошибка» | 3 251 214 (71,0 % ответов) |
| Замечания без ответа | 1 113 387, из них **865 996 не отвечаемы по построению** |
| Адресуемо в цикле 2026 | 2 033 989 из 2 908 225 = **69,9 %** |

## Что в репозиторий не идёт (§2)

- каталог `_MASTER_OUTPUT` и построчные выгрузки — собранные данные;
- мастер-таблица журналов, реестр жизненного цикла, несопоставленные ответы —
  содержат ИИН/БИН и идентификаторы договоров; в переданный пакет они тоже не входили;
- приложения Б3 и Б4 — формулировки регулятора и тексты ответов банка: это переписка,
  а не агрегат.

В репозитории — выводы, перечень инициатив, перечень контролей и **код сборки
документов**. Word-файлы не коммитятся: они воспроизводятся из `build/` одной командой,
а `.docx` не диффится, поэтому правка в нём незаметна в PR.

```
cd build && npm install docx && node audit.js && node roadmap.js
```
