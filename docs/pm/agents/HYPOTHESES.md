# Гипотезы офиса агентов

На них держится редакция 2 `PROTOCOL.md`. Ни одна не проверена на данных этого
репозитория: исследований LLM-агентов на задачах кредитного риска нет, сравнения
«человек-диспетчер против LLM-оркестратора» нет. Проверяются пятничной routine по метрикам
`PROTOCOL.md` §8; срок первой сверки — 23.10.2026 (две недели), решение — 06.11.2026.
Отзыв гипотезы — явной записью ниже, с прежней формулировкой (§5 корневого `CLAUDE.md`).

| № | Гипотеза | Чем проверяется | Что её опровергнет | Статус |
|---|---|---|---|---|
| Г-1 | Пропускная способность офиса ограничена числом решений автора в день, а не числом агентов | решений, вынесенных автору в день, против решений, принятых в тот же день | рост числа сессий даёт пропорциональный рост слитых PR без роста очереди «ждёт автора» | открыта |
| Г-2 | Секретарь без долгой памяти ничего существенного не теряет, если протокол хода §5 соблюдается | пропуски на доске против фактического состояния issue | на доске регулярно нет пунктов, которые есть в issue | открыта |
| Г-3 | Страховочный предел передачи дел — 25–30 % окна | доля отозванных находок и переделанных PR по сессиям выше и ниже предела | качество не зависит от заполнения окна в диапазоне 30–70 % | открыта |
| Г-4 | Сокращать CLAUDE.md надо за счёт пояснений, а не правил, предотвращающих ошибки | нарушения правил до и после сокращения | после сокращения растут нарушения Б1/§2/§4 | открыта |

| Г-6 | Issue надо резать на куски ≲ 1 ч экспертного труда (80-процентный горизонт METR) | доля issue, закрытых одной сессией без передачи дел | крупные issue закрываются одной сессией не хуже мелких | открыта |
