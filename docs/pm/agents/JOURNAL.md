# Журнал ведения проекта

Один файл, только дописывается. Запись: дата, решение или случай, причина, результат,
источник. Прежние записи не правятся; отзыв — новой записью со ссылкой на прежнюю
(§5 корневого `CLAUDE.md`).

Репозиторий публичный. В журнал не попадают ИИН, ФИО, номера договоров, значения
из рабочих файлов банка, пароли, текст писем ИБ, содержание замечаний АФР и результаты
проверки. Коллеги — инициалами.

---

### Ж-1. 05.11.2026 — порядок двух сессий

- **Решение.** Облачная сессия отвечает за репозиторий, локальная — за диски банка
  и приёмку пересчётом; решения принимает MZ. Код пишет облачная, на настоящих данных
  запускает локальная. Данные в облако не уходят.
- **Причина.** Разделение зон ответственности и защита данных.
- **Результат.** Первые задания по этому порядку: W1 (скрипт проверки покрытия),
  W2 (этот журнал).
- **Источник.** Решение MZ, передано локальной сессией 05.11.2026.

### Ж-2. 05.11.2026 — поверхностный результат сессий-исполнителей

- **Случай.** Сессии-исполнители давали поверхностный результат: без доступа к файлам
  они могут только писать текст.
- **Причина.** Запреты после случаев с ПДн ввели, но нового пути к данным не дали.
- **Решение.** Сначала проверка на одной задаче с заранее зафиксированным эталоном;
  инфраструктура строится только под неё.
- **Результат.** Открыт; итог проверки — отдельной записью.
- **Источник.** Решение MZ, передано локальной сессией 05.11.2026.

### Ж-3. 05.11.2026 — критерий проверки

- **Решение.** Проверка пройдена, если одновременно: числа и источники совпали
  с эталоном; ни одной утечки ПДн; общее время вместе с проверкой человеком минимум
  на 30 % меньше базового. Статусы «Сдано» и «Принято» ставит только человек.
- **Причина.** Критерий фиксируется до прогона (§6 корневого `CLAUDE.md`), иначе любой
  результат окажется подтверждением.
- **Результат.** Принят как критерий для Ж-2.
- **Источник.** Решение MZ, передано локальной сессией 05.11.2026.

### Ж-4. 05.11.2026 — «закрыто» в трекере не равно подтверждению регулятора

- **Решение.** Статус «закрыто» в рабочем трекере — вывод сессии, а не подтверждение
  регулятора. Эталон готовит человек по первоисточникам, не по трекеру.
- **Причина.** Трекер заполняют те же сессии, чью работу проверяют; эталон из него
  проверял бы сессию её собственным выводом (причина сформулирована облачной сессией,
  не MZ).
- **Результат.** Принято.
- **Источник.** Решение MZ, передано локальной сессией 05.11.2026.

### Ж-5. 05.11.2026 — приём результата агента

- **Решение.** Результат агента принимается независимым пересчётом другим кодом,
  а не по его отчёту.
- **Причина.** Отчёт и расчёт делает один исполнитель; ошибка расчёта воспроизводится
  в отчёте (причина сформулирована облачной сессией, не MZ).
- **Результат.** Применяется с W1: скрипт пишет облачная сессия, итог сверяет локальная
  своим пересчётом.
- **Источник.** Решение MZ, передано локальной сессией 05.11.2026.
